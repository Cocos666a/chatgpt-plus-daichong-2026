## 共同的判断标准

不管充哪个平台，判断一家是否可靠，看这五条：

1. **要不要求你给账号密码？** 要求的，风险最高
2. **要不要求你提供登录验证码？** 要求的一律拒绝
3. **封号赔不赔？** 敢明说不赔的，比含糊其辞的可信
4. **有没有真实经营主体？** 公司还是个人，能不能查到
5. **价格是不是低得离谱？** 低于官方价 50% 的，基本是合租号或来源不明
